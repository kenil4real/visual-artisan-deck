# Premium Video Production Studio Website

## What I’ll build
- Replace the starter screen with a complete one-page creative production studio experience.
- Follow the requested story arc: cinematic opening, moving wordmark, studio statement, services, featured capabilities, selected work, showreel, industries, benefits, process, studio difference, testimonial placeholder, inquiry, and footer.
- Keep all missing business details visibly marked as placeholders; no invented clients, claims, awards, team members, locations, statistics, or testimonials.

## Visual direction
- Original editorial composition inspired by the reference’s confidence, scale, whitespace, typographic rhythm, asymmetry, and media-first pacing—not its exact layout or assets.
- Near-black, paper-white, and a restrained signal-red accent with sharp geometry and oversized grotesk typography.
- Generated production imagery for the actual page: film set, product shoot, aerial work, industrial footage, studio photography, and behind-the-scenes moments.
- Responsive art direction for desktop, tablet, and mobile, including a full-screen mobile menu.

## Interaction and motion
- Lightweight sticky navigation that changes treatment over media and page content.
- Line-by-line opening reveal, continuous marquees, restrained scroll reveals, image scaling, service previews, a cinematic showreel overlay, and an active-step production timeline.
- Reduced-motion fallbacks, keyboard support, visible focus states, semantic structure, and accessible media controls.

## Content and functionality
- Data-driven service, project, industry, benefit, and process sections for easy expansion.
- Premium project inquiry form with all requested fields, client-side validation, accessible errors, file attachment, and an honest demo submission confirmation because no destination or email service was supplied.
- Clearly labeled sample portfolio and testimonial placeholders that never imply real client work.

## Technical details
- Use the existing React/TanStack Start and Tailwind v4 project.
- Build focused reusable components, semantic design tokens, and responsive image sizing.
- Add unique page metadata, Open Graph/Twitter tags, and Organization structured data using placeholders where company identity is unknown.
- Verify the rendered page and key interactions at desktop and mobile sizes, then check for console errors and layout overlap.
